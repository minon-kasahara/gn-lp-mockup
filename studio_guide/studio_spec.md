### 3.3 主要コンポーネントの詳細パラメータ

#### 3.3.1 Section

🔬 観測（FV(Hero) Section が `<section>` タグで生成）

- HTML タグ: `<section>`
- 用途: LP の意味論的なセクション区切り
- ボックスタブ: 全項目（幅/高さ/パディング/方向/ギャップ/配置/外観/ポジション）
- 設定タブ: リンク / HTML タグ変更 / メタ情報
- アンカー設定: ID 属性をセクションに付与すれば、Nav からのスクロール先に
- 推奨用途: 各 §5-N（FV / Problem / Approach / Service / Record / VC / Cases / CTA / Footer）

#### 3.3.2 Loop Box

📚 公式: https://help.studio.design/en/articles/13713839

| パラメータ | 値 | デフォルト | 備考 |
| --- | --- | --- | --- |
| **速度** | px/s | **60** | 数値入力 or スライダ。高いほど速い |
| **方向** | 横 / 縦 / 左→右 / 右→左 / 上→下 / 下→上 | 子要素の並び方向に依存 | 子の方向設定で決まる |
| **Pause on hover** | ON / OFF | ON | マウスホバーで一時停止 |
| **プレビュー** | 再生 / 停止 トグル | — | エディタ内で動作確認可 |

##### 使い方

1. 追加パネル → 基本タブ → インタラクション → **Loop Box**
2. キャンバスにドラッグ
3. **子要素を追加**（Box / Image / Text 等、ループしたいもの）
4. 子要素の並び方向に応じて自動的に Loop 方向が決まる
5. Loop Box 自体の右パネルで速度・hover 設定

##### 利点

- ✅ Studio エディタ内でアニメーションを**プレビュー可能**（Embed と異なり）
- ✅ Free プランでも利用可能
- ✅ 子要素は通常の Studio コンポーネント（Image / Text 等）として配置・編集できる

#### 3.3.3 Form1 / Form2 / Form3

🟡 観測（追加パネル）。詳細仕様は要追加調査

- 既製フォームテンプレート 3 種
- フォームパーツ（Input / Textarea / Select 等）を組み合わせた構成
- 設定タブで送信先（メール / Webhook / Studio CMS / 外部サービス）を設定
- 確認画面（Confirm）対応の有無は要確認

#### 3.3.4 Lottie

📚 一般的仕様

- Lottie アニメーション JSON ファイルを再生
- 設定: src / 自動再生 / ループ / 速度
- LP のヒーロー演出・スクロール連動等で活用

#### 3.3.5 RichText vs Text

| 観点 | Text | RichText |
| --- | --- | --- |
| 用途 | 単一の見出し・短文・ラベル | 複数段落・リスト・装飾混在の本文 |

## 5. 配置プルダウンの正確な対応

🔬 本プロジェクトで検証済（2026-05-07）

### 水平（Justify）プルダウンの選択肢

| Studio 表記 | CSS justify-content | 挙動 |
| --- | --- | --- |
| 左寄せ | `flex-start` | 全 item を左に寄せる |
| 中央寄せ | `center` | 全 item を中央に |
| 右寄せ | `flex-end` | 全 item を右に寄せる |
| **均等** | **`space-between`** | **両端配置・端には余白なし** |
| 均等（余白含む） | `space-around` または `space-evenly` | 端にも等しい余白を入れる |

> ⚠️ Studio に「**両端揃え**」という表記は**存在しない**。`space-between` を実現するには「**均等**」を選択する。
> ⚠️ 「均等（余白含む）」が space-around / space-evenly のどちらかは要追加検証。

### 垂直（Align）プルダウンの選択肢

| Studio 表記 | CSS align-items | 挙動 |
| --- | --- | --- |
| 上 | `flex-start` | 上端揃え |
| 中央寄せ（中央揃え）| `center` | 縦中央 |
| 下 | `flex-end` | 下端揃え |

> ⚠️ stretch / baseline の対応は要追加調査。

### ビジュアルインジケータ

## 6. Auto width と Flex の挙動

🔬 本プロジェクトで検証済（2026-05-07・CTA ボタン）

### 重要仕様

📚 公式: https://help.studio.design/en/articles/2639205

> 「親ボックスを auto に設定し、子ボックスを % に設定する場合は機能しない」

### 観測した挙動

- **親 Box が幅 auto** の場合、内容にぴったり合わせたサイズになる
- このとき配置「均等」（space-between）を設定しても、**items を端に push する余地がない**ため視覚的に変化が見えない
- items は単に左から詰めて配置される

### 解決策

| 方法 | 内容 |
| --- | --- |
| **A. 親 Box の幅を固定値に** | px or % で具体値を設定。これで items を端に分散できるスペースが生まれる |
| B. 親の親で幅を確保 | 親の親が広いなら親に `width: fill` 系で広げさせる（要追加検証）|
| C. spacer Box を挿入 | 子要素の間に空 Box を `flex: 1` で挿入（Studio の flex 単位）|
| D. margin auto trick | items の片方に margin-left: auto（要 Studio で検証） |

🔬 本プロジェクトで採用: A（CTA ボタン: 無料相談 = 135px / 資料DL = 180px）

### 単位対応表（再掲）

| 単位 | 用途 |
| --- | --- |
| px | 固定値 |
| % | 親に対する割合 |
| auto | 内容に合わせる |
| flex | 兄弟要素間の幅比率 |
| vw / vh / dvh | ビューポート基準 |

## 10. Embed コンポーネント

📚 公式: https://help.studio.design/en/articles/4064934

### 仕様

- **全プランで利用可能**（Free でも使える）
- HTML / CSS / JavaScript を直接記述可能
- 文字数上限: **30,000 文字**（per Embed）
- ✅ Studio の `</>`（Embed）アイコンから配置

### 埋め込みタイプ（自動判定）

| タイプ | 自動分類条件 | 挙動 |
| --- | --- | --- |
| **iframe** | コードが**`<iframe>` タグのみ** | YouTube / Formrun / HubSpot Forms 等 |
| **sandbox** | **iframe 以外**の全コード（HTML/CSS/JS/SVG 等） | 隔離された描画コンテキスト |

> ⚠️ ユーザーが選ぶプルダウンではなく、**コード内容で自動判定**。
> ⚠️ HubSpot Forms を CMS プロパティで埋め込む場合は自動的に sandbox に切替。

### sandbox 仕様

- iframe で隔離されるため、外部の Studio 全体スタイルの影響を受けない
- 内部の `<style>` も外部に影響しない
- iframe のデフォルトサイズが SVG コンテンツより大きい場合、**余白が発生**する → Box の幅・高さを固定するか、SVG を `width:100%; height:100%` に

### エディタプレビューの限界

- ⚠️ Studio エディタ内では**動作確認できない**
- **Publish して公開URLで確認**が必須

🔬 本プロジェクトで使用: G&N ロゴ SVG（sandbox 自動判定）

## 16. Content Edit Mode

📚 公式: https://help.studio.design/en/articles/6510478

### 用途

テキスト・画像などの**内容のみ**を編集可能にし、デザイン変更を防ぐモード。

### 切替

- **画面左下の鉛筆アイコン**をクリック
- または **`C` キー**

### このモード時にできること

- 画像ボックス内の画像置き換え

### モードはアカウント単位

- 他メンバーの編集モードに影響しない

### 抜け方

- 「Exit Content Edit Mode」or 鉛筆アイコン再クリック

> 🔬 本プロジェクトで「Base レイヤーの塗りが編集できない」現象が発生。Content Edit Mode が原因の可能性 → 切替で確認したが解消せず → Base 自体に該当 UI が無いと結論（§12 参照）

## 17. Position の挙動

🔬 検証

| 値 | 挙動 |
| --- | --- |
| 相対（relative）| 通常フロー位置からの相対指定 |
| 絶対（absolute）| 親（最近の position 相対以外）からの絶対指定 |
| **固定（fixed）** | **ビューポートに固定**。スクロールしても追従。Header で使用 |
| スティッキー（sticky）| スクロール位置に応じて固定/通常切替 |

### 固定（fixed）使用時の追加項目

- 距離（top / right / bottom / left）入力欄が表示
- 重ね順（z-index）で前後関係を制御

🔬 本プロジェクトで使用: Header に **位置: 固定 / top: 0 / left: 0 / 重ね順: 100**

## 付録 A: 既知の落とし穴

🔬 本プロジェクトで遭遇した問題と解決策

| 落とし穴 | 原因 | 解決 |
| --- | --- | --- |
| Embed の SVG に灰色背景 | sandbox iframe 自体の background-color | 当該 Embed Box の背景色を「なし」に |
| Logo が Header 内に表示されない | Logo 子要素 (Embed) の幅 / 高さ未設定 | 幅 92px or auto + 高さ 30px に設定 |
| 配置「均等」で items が分散しない | 親 Box が auto width で extra space なし | 親 Box の幅を固定値に |
| 「両端揃え」が見つからない | Studio に該当表記なし | 「**均等**」を選択（= space-between） |
| Logo Box に余分な余白 | Embed sandbox の固有サイズ | Embed Box の幅を SVG ぴったりに固定（92px 等） |
| Custom Code が使えない | Free プラン制約 | Embed コンポーネントで代替 |
| Base レイヤーの塗り設定 UI 不在 | Studio 仕様 | ページ背景は各セクションで設定 |
