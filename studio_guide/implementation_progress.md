## 前提プラン

- **方針（2026-06-18 確定）**: **最終的に Mini プラン**（カスタムドメイン / Studio バナー非表示 / Custom Code 解禁）。
- **実装中のプラン**: 要判断。最終 Mini なら **制作段階から Mini に前倒しすると効率的**（Custom Code で `<style>` 注入可 → 疑似要素 ::before/::after 計67・グラデ44・@keyframes 6 の「要素分解」作業がほぼ不要）。Free のまま進める場合は各章の【Free代替】に従う。手順書 v02 は両対応。
- 🔴 **要確認（Mini の落とし穴）**: **Mini はページ数上限が実質2ページ（+404）**。本LPは既に `privacy.html`（プライバシー）を持ち、フォーム送信後のサンクスページも想定されるため、**LP本体＋PP＋サンクス=3ページで Mini(2) を超過する可能性**。超過する構成なら **Personal（150ページ）** が必要。公開時のページ構成（必要ページ数）を早めに確定すること。→ リファレンス §1.2 / 付録A。
